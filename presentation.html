RVM — Reverse Vending Machine

A smart full-stack recycling management system that combines a Vue.js web app, a Laravel REST API, and an AI-powered material classifier to incentivise sustainable behaviour.

Web Technologies · Semester 2
The Problem

Why do we need an RVM?

🗑️

Low recycling rates

Most recyclable items end up in general waste because the process is inconvenient and unrewarding.

❓

No incentive

People are not motivated to sort and deposit recyclables when there is no immediate reward.

📊

Zero visibility

Facility managers have no real-time data on machine capacity or recycling volume.

Our Solution

A smart, gamified recycling platform

The RVM system connects physical reverse vending machines to a mobile-friendly web app. Users scan a QR code, insert their recyclable item, and the machine automatically classifies it using computer vision, weighs it, and awards points — creating a positive feedback loop that turns recycling into a rewarding habit.

Technology

Full-Stack Tech Stack

Frontend
Vue.js 3 + Vite

SPA with Pinia state management, Vue Router, and TailwindCSS. Supports dark/light themes and EN/ID localisation.

Backend
Laravel 10

REST API with Sanctum token auth, Google OAuth via Socialite, and WhatsApp OTP via the Fonnte API.

AI Service
Python · Flask · YOLOv8

Microservice running a YOLOv8n object-detection model to classify recyclable materials from captured images.

Database
MySQL 8.0

7 normalised tables covering users, machines, sessions, transactions, QR sessions, and audit logs.

Auth
Sanctum + Socialite

Stateless API token authentication with optional Google OAuth social login and WhatsApp OTP 2FA.

Dev Environment
Laragon + phpMyAdmin

Local Apache + MySQL server managed by Laragon for rapid development and database inspection.

Flask / YOLOv8

The Vue SPA communicates exclusively with the Laravel API over HTTPS. The API handles all business logic and persists data in MySQL. For material classification, the API calls the Flask microservice, which runs YOLOv8n inference and returns the detected category.

Features

Key Features

📷

AI Material Classification

YOLOv8n computer vision identifies aluminium, plastic, glass, and paper from a captured photo.

🏆

Points Gamification

Users earn points per 100 g of recyclable material deposited. Invalid items incur a deduction.

📲

QR Session Linking

Each RVM displays a unique QR code. Scanning it on the mobile app binds the user to that machine session securely.

🌐

Dual Language & Theme

Full English / Bahasa Indonesia localisation plus seamless dark and light mode switching.

🖥️

Kiosk Mode

A dedicated display interface for the physical RVM hardware — no login required at the machine.

🗺️

RVM Locator (Maps)

Google Maps integration lets users find the nearest reverse vending machine by location.

AI / Machine Learning

YOLOv8 Material Classifier

How it works

  • Camera captures image of inserted item
  • Laravel API sends image to Flask microservice
  • YOLOv8n model runs object detection
  • Top predicted class returned to API
  • API validates against user's selection

Tech details

  • Model: Ultralytics YOLOv8n (best.pt)
  • Runtime: Python 3.10 + Flask
  • Image processing: Pillow library
  • Secured with X-API-Key header
  • Mock mode available when no model loaded

The AI microservice runs independently on port 5000, keeping it isolated from the main Laravel app and easy to retrain or replace without touching the API.
