Our Approach

The RVM System automates the entire recycling journey — from item deposit to reward — using a QR-linked mobile app, AI material detection, and a gamified points economy.

Tech Overview

Three-tier architecture: a Vue.js 3 SPA for users and admins, a Laravel 10 REST API handling business logic and auth, and a Flask microservice running YOLOv8 AI inference.

👥

Who Uses It

Users — scan, deposit, and earn points via the mobile web app.

Admins — manage machines, monitor sessions, and view analytics.

Kiosk — the physical RVM machine display.

How the System Works

🔐

1. Auth

User registers or logs in via email, phone, or Google OAuth. WhatsApp OTP optional.

›
📲

2. Connect

User scans the QR code on the physical RVM. A secure session links the phone to the machine.

›
♻️

3. Recycle

User deposits item. Machine captures image, runs AI classification, weighs, and validates.

›
🏆

4. Reward

Points are credited to the user's account. Session summary shown. Admin data updated.

Main Features
05 · Features

Main Features

🤖

AI Material Classification

YOLOv8n object detection model running in a Flask microservice automatically identifies aluminium, plastic, glass, or paper from a captured image.

YOLOv8 · Flask · Pillow
🏆

Points Gamification

Users earn points based on material type and weight. Invalid items trigger a deduction, encouraging correct sorting and honest deposits.

10 / 8 / 6 / 5 pts per 100 g
📲

QR Session Linking

Each RVM displays a dynamically generated QR code. Scanning it from the mobile app binds the user to that specific machine for the session.

Laravel QR · Sanctum token
🌐

Multi-Language & Theme

Full English and Bahasa Indonesia localisation via vue-i18n, with seamless dark and light mode switching using CSS variables.

vue-i18n · TailwindCSS
🖥️

Kiosk & User Interfaces

Two separate UX modes: a mobile-first interface for users and a public kiosk display for the physical machine — no login required at the kiosk.

Vue Router · Pinia guards
📊

Admin Control Panel

Full management dashboard: user control, machine bin monitoring with alerts, session/transaction logs, analytics, and a complete audit trail.

40 + REST endpoints
Expected Output
06 · Expected Output

What the System Delivers

01

Functional Web Application

A fully working multi-page Vue.js SPA accessible from any device browser.

  • Registration & login (email / Google / OTP)
  • QR scanner for machine linking
  • Interactive 14-step recycling session
  • Session summary & points history
02

REST API Backend

A robust Laravel 10 API serving all business logic with 40+ endpoints.

  • Token-based authentication (Sanctum)
  • Google OAuth social login
  • WhatsApp OTP verification
  • Role-based access control
03

AI Classification Service

Standalone Flask microservice classifying recyclable materials in real time.

  • YOLOv8n model (best.pt)
  • 4 material categories detected
  • API-key secured endpoint
  • Mock fallback when no model
04

Points & Engagement

A live gamification layer that drives user behaviour and recycling habits.

  • Instant points credit per deposit
  • Points deduction for invalid items
  • Full history & balance tracking
  • Session summary breakdown
05

Admin Analytics

Actionable insights for facility managers and administrators.

  • Real-time bin fill level monitoring
  • Full-bin alerts & machine status
  • Session & transaction audit logs
  • Material volume statistics
06

Kiosk Interface

A dedicated screen UI for the physical RVM hardware.

  • Dynamic QR code generation
  • No user login required at machine
  • Google Maps RVM locator
  • Real-time status display
