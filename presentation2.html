What is the RVM System?

🌍

The Problem in Malaysia

Malaysia generates in excess of 39,000 tonnes of solid waste each day. A significant proportion of this material is recyclable, yet the majority is directed to landfill — primarily because the public has no structured incentive to behave otherwise.

Our Approach

Malaysia's national target is a 40% recycling rate by 2025. Achieving this objective demands more than public awareness campaigns — it necessitates sustained behavioural change. The RVM System addresses this directly by incentivising individuals at the point of deposit, making responsible disposal both accessible and rewarding.

Why It Matters Now

Research from Universiti Malaya demonstrates that Malaysians hold positive attitudes towards recycling, yet actual participation rates remain consistently low. The barrier is not a lack of awareness — it is the absence of tangible incentive. Peer-reviewed studies confirm that direct rewards represent the most effective mechanism for encouraging sustained recycling behaviour. (Universiti Malaya & ScienceDirect, 2022–2024)

👥

Who Uses It

End Users — register, scan a QR code, deposit recyclable items, and accumulate reward points via the mobile application.

Administrators — oversee machine operations, monitor active sessions, and review analytical reports.

Kiosk Display — the on-site screen embedded within the physical RVM unit.

How the System Works

🔐

1. Registration

The user registers or signs in via email, phone number, or Google. Identity is verified via a WhatsApp one-time code where required.

›
📲

2. Connection

The user scans the QR code displayed on the machine. The system immediately associates their account with that specific RVM unit.

›
♻️

3. Deposit

The user deposits their item. The machine captures an image, the AI engine identifies the material type, and the weight is recorded automatically.

›

Points are immediately credited to the user's account. A session summary is presented and all records are updated for management reporting.

Main Features
05 · Features

Main Features

🤖

AI Material Classification

An artificial intelligence model automatically identifies the category of material deposited — aluminium, plastic, glass, or paper — from an image captured within the machine, requiring no human verification whatsoever.

AI Vision · 4 material categories
🏆

Rewards & Engagement

Participants accumulate points for each item deposited, with higher allocations awarded for premium materials. Incorrectly classified deposits result in a proportionate deduction, encouraging accurate sorting and responsible conduct.

Points per deposit · Instant balance update
📲

QR Machine Pairing

Each unit displays a unique QR code which the user scans once via their mobile device. The system immediately associates their account with that machine — no additional credentials, PIN, or manual input required.

Scan-to-start · Secured session · Auto-expiry
🌐

Multi-Language & Accessibility

Comprehensive support for English and Bahasa Malaysia broadens the platform's accessibility across diverse user groups. Selectable dark and light display modes ensure usability in any environment or lighting condition.

English · Bahasa Malaysia · Dark / Light mode
🖥️

Kiosk & User Interfaces

Two purpose-built interfaces: a mobile-first application for end users and a dedicated display for the physical machine. The kiosk operates in a public-facing mode with no user credentials required on the device itself.

Mobile-first · Public kiosk display · No device login
🔑

Flexible Sign-In Options

Users may authenticate via email and password, a linked Google account, or a one-time verification code delivered through WhatsApp — reducing barriers to registration and broadening adoption across all demographics.

Email · Google Sign-In · WhatsApp OTP
Expected Output
06 · Expected Output

What the System Delivers

01

User-Facing Web Application

A fully operational, browser-based application accessible from any smartphone without requiring installation.

  • Registration via email, Google, or WhatsApp
  • QR code scanning to pair with any RVM unit
  • Guided, step-by-step recycling session
  • Points balance, transaction history, and session summary
02

Secure System Backend

A robust server infrastructure managing all user accounts, transactions, and machine data across 40+ operational endpoints.

  • Secure user authentication and session management
  • Google Sign-In and WhatsApp OTP integration
  • Distinct access levels: End User, Administrator, Machine
  • Comprehensive transaction and activity records
03

AI Identification Engine

An intelligent classification service that identifies the category of recyclable material deposited in real time, without the need for staff involvement.

  • Identifies aluminium, plastic, glass, and paper
  • Confidence rating recorded per deposit
  • Isolated, secured classification service
  • Fallback mode guarantees continuous operation
04

Reward & Loyalty Engine

A real-time incentive framework that transforms recycling into a measurable and consistently rewarding activity for all participants.

  • Points credited immediately upon each deposit
  • Deduction applied for incorrectly classified material
  • Full points history and current balance accessible at all times
  • Per-session summary with an itemised breakdown
05

Management Dashboard

Data-driven insights that enable facility administrators to make informed operational decisions remotely.

  • Real-time bin capacity alerts prior to overflow
  • Seven-day recycling volume trends by material type
  • Full session and transaction audit trail
  • Exportable reports and configurable reward allocations
06

Machine Display Interface

A public-facing screen designed specifically for the physical RVM unit — continuously operational, with no user account required at the machine itself.

  • Auto-refreshing QR code for account pairing
  • Secured machine-to-system connection
  • Google Maps integration for locating nearby units
  • Live machine status displayed at all times
