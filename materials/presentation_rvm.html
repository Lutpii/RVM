Background & Introduction

Why a Reverse Vending Machine?

⚠️  The Problem
Recycling rates remain critically low in Malaysia — only ~23% of solid waste is recycled annually
Lack of tangible incentives drives low public participation in recycling programmes
Manual material sorting is error-prone, inefficient, and labour-intensive
Recyclable waste frequently ends up in landfills due to poor collection infrastructure
Communities lack real-time visibility into bin capacity and machine availability
✅  Our Solution: RVM System
Smart kiosk that accepts recyclable materials: Aluminum, Plastic, Glass & Paper
AI-powered material classification using YOLOv8n deep learning model (≥60% confidence)
Gamified reward system — users earn redeemable points per gram of material deposited
Real-time bin-level monitoring and machine status tracking via admin dashboard
Full-stack platform: Vue.js frontend + Laravel API backend + Python Flask AI service
📌  This project is developed by UMPSA students as a collaboration deliverable for DSME Engineering. The system bridges sustainable recycling practices with modern IoT and AI technologies, creating a scalable, data-driven solution for smart waste management.

Main Features

Core capabilities of the RVM Smart Recycling System

🤖

AI Material Classification

  • YOLOv8n deep learning model
  • 4 classes: Aluminum, Plastic, Glass, Paper
  • 60% confidence threshold
  • Bounding box detection & scoring
  • Mock fallback mode for testing
🔐

Multi-Authentication System

  • Email & password registration
  • WhatsApp OTP via Fonnte API
  • Google OAuth 2.0 sign-in
  • Laravel Sanctum token-based auth
  • Role-based access: User / Admin
📊

Real-Time Monitoring

  • Live bin-level per material type (0–100%)
  • Machine status: Active / Maintenance
  • GPS location with Google Maps embed
  • Alert threshold at 90% bin capacity
  • Admin session & transaction audit logs
🏆

Points & Rewards Engine

  • Aluminum → 10 pts / 100g
  • Plastic → 8 pts / 100g
  • Glass → 6 pts / 100g
  • Paper → 5 pts / 100g
  • −10 pts for rejected items
📱

User Experience

  • 14-step guided recycling session UI
  • QR code kiosk linking (mobile scan)
  • Bilingual: English & Bahasa Indonesia
  • Dark / Light theme toggle
  • Mobile-responsive, PWA-ready layout
⚙

Tech Stack

  • Frontend: Vue.js 3 + Pinia + Vite
  • Backend: Laravel 10 + MySQL 8
  • AI Service: Python Flask + YOLOv8n
  • Auth: Sanctum + Socialite + Fonnte
  • Charts: Chart.js  |  QR: qrcode.js
